Project Overview

This project follows the ITIS 3135 design plan by building five core pages with consistent navigation, meaningful content, and interactive functionality.

Project Overview

The Kangaroo Tech Lab website supports a small business-style student project focused on accessible information, product details, and user interaction.

  • Delivers clear business and project information.
  • Organizes navigation, forms, product listings, and inventory details.
  • Supports dynamic content with a project plan JSON file.

Intended Users

  • Local customers browsing products and services.
  • Community members looking for updates and inventory.
  • Students reviewing the website structure and project plan.
  • Instructors evaluating the static site design and interactivity.

Website Content Overview

The site includes the following content categories:

  • Home page introduction and navigation.
  • Project overview and design documentation.
  • Interactive introduction form with validation.
  • Product details and visual gallery.
  • Inventory items with search and filter controls.

Page Design Summary

  1. Home - introduces the site and links to all pages.
  2. Project Overview - documents the plan, audience, and data strategy.
  3. Introduction Form - captures visitor details and displays a summary.
  4. Product - showcases products, services, and benefits.
  5. Inventory - lists available inventory with search and category filters.

Page Design Details

Home

Purpose: welcome visitors and offer clear navigation. Includes real content and a strong hero section.

Project Overview

Purpose: present requirements, client details, diagrams, and dynamic project data. Audience: instructors and stakeholders.

Introduction Form

Purpose: collect visitor input and demonstrate interactive form validation. Audience: users interested in the project.

Product

Purpose: describe products and services with images. Audience: customers and reviewers.

Inventory

Purpose: provide a searchable inventory listing. Audience: customers and team members.

Dynamic Functionality

This page loads the project plan data from a JSON file using AJAX-style fetch and updates the page content dynamically.

  • AJAX data loading via fetch.
  • External JavaScript file for page behavior.
  • Consistent navigation and shared styling across pages.
