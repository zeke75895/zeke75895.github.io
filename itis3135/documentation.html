Variables and Scope

Variables are containers for storing data values. In JavaScript, variables are declared with var, let, or const.

The let keyword declares a block-scoped variable, while var declares a function‑scoped or globally‑scoped variable.

const creates a constant reference that cannot be reassigned. However, if the value is an object, its properties can still be modified.

Scope determines the accessibility of variables. Global variables are accessible everywhere; local variables are limited to the function or block they are defined in.

let x = 10;
    const PI = 3.14;
    if (true) {
    let y = 20;  // block scoped
    var z = 30;  // function scoped (or global if not inside function)
    }

Understanding scope helps avoid naming conflicts and unintended mutations.

  • var – function scope, hoisted, can be redeclared.
  • let – block scope, not hoisted in the same way, cannot be redeclared in same block.
  • const – block scope, must be initialized, cannot be reassigned.
Data Types

JavaScript has dynamic typing. The same variable can hold different types. Primitive types include string, number, boolean, null, undefined, symbol, and bigint.

Everything else is an object (including arrays, functions, dates). Use typeof to inspect the type.

Strings can be created with single quotes, double quotes, or backticks (template literals).

Numbers are always floating‑point; there is no separate integer type. Special numeric values: NaN, Infinity.

let age = 25;               // number
    let name = "Ada";           // string
    let isLogged = true;        // boolean
    let empty = null;           // null
    let notDefined;             // undefined
  • Use Number() or parseInt() for conversion.
  • BigInt is for integers larger than 2^53-1.

Type coercion happens automatically in comparisons and arithmetic.

Functions and Closures

Functions are first‑class objects. They can be declared with the function keyword or as arrow functions (=>).

A closure is formed when a function retains access to its outer (lexical) scope even after the outer function has returned.

function outer() {
    let count = 0;
    return function inner() {
        count++;
        return count;
    };
    }
    const counter = outer();

Closures are useful for data encapsulation and creating factory functions.

Arrow functions do not have their own this and are not suitable for methods that need dynamic context.

  • Function declaration vs expression
  • Parameters and default values (function(a, b = 1))
  • Rest parameters ...args
  • Immediately Invoked Function Expressions (IIFE)

Higher‑order functions accept or return other functions.

Control Flow

Control flow statements determine the order in which code executes. Conditional statements: if...else, switch.

Loops: for, while, do...while, and for...in (for object properties) or for...of (for iterables).

let i = 0;
    while (i < 3) {
    console.log(i);
    i++;
    }

    for (let j = 0; j < 3; j++) {
    if (j === 1) continue;  // skip iteration
    console.log(j);
    }

Break exits a loop early; continue skips to the next iteration.

Switch compares using strict equality (===).

  • if...else if...else
  • switch (expression) { case value: ... }
  • for...in vs for...of

Logical operators (&&, ||, !) are often used to short‑circuit.

Objects and Prototypes

Objects are collections of key‑value pairs. They can be created using object literals {}, constructors, or Object.create().

Every object in JavaScript has a prototype (except the root object). The prototype chain is used for inheritance.

const person = {
    name: 'Lee',
    greet() {
        return `Hi, I'm ${this.name}`;
    }
    };
    console.log(person.greet());

ES6 introduced classes (syntactic sugar over prototypes).

You can access properties with dot notation or brackets obj['prop'].

  • Prototype property vs __proto__
  • Constructor functions and new keyword
  • hasOwnProperty vs inherited properties
  • Object methods: keys(), values(), assign()

Arrays are special objects with numeric keys and a length property.

Error Handling

JavaScript provides the try...catch statement to handle runtime errors gracefully. The finally block runs regardless of an error.

try {
    let result = riskyOperation();
    console.log(result);
    } catch (error) {
    console.error('Caught error:', error.message);
    } finally {
    console.log('Cleanup actions');
    }

You can throw your own errors using throw new Error('message'). Error types: TypeError, ReferenceError, SyntaxError, etc.

Proper error handling prevents application crashes and improves user experience.

  • Always catch specific errors when possible.
  • Use finally for closing resources.
  • Custom error classes can extend Error.
  • Avoid throwing non‑Error objects.
  • Async errors need .catch() or try/catch with async/await.

Debugging with console methods or browser dev tools is common.
